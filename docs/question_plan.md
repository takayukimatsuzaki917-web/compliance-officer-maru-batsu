## 品質管理の手順（各バッチ共通）

1. 一次情報（e-Gov法令検索、金融庁の監督指針、生命保険協会の公開ガイドライン）を取得して読む
   - 取得できない資料は推測で書かず、`docs/sources/` へのPDF配置を依頼する
2. 市販の問題集・テキスト・協会資料の文章を転載・言い換えせず、すべて自作する
3. 条番号・章まで一次情報で確認できた問題だけ `status: "reviewed"` にする
4. `python scripts/validate_questions.py` でスキーマ検証
5. `python scripts/question_stats.py` で配分・○✕比・難易度比を確認
6. `python scripts/check_similarity.py` で類似・重複を確認
7. コミット（`feat(data): バッチN（…）を追加`）

## 第2パス（全バッチ完了後）

- 全問について「問題文・解答・根拠」が整合しているかを再検証する
- 疑義があるものは `docs/review_needed.md` に一覧化する
